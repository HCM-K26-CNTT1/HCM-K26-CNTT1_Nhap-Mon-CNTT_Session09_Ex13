# 🚀 SmartCampus

SmartCampus là ứng dụng di động **hỗ trợ sinh viên PTIT** tra cứu *lịch học*, phòng học trống và nhận thông báo mới nhất từ nhà trường.

## ✨ Tính năng đã hoàn thành

- Tra cứu lịch học theo mã sinh viên.
  - Giúp sinh viên xem lịch học của mình.
- Xem danh sách phòng trống theo tòa nhà.
  - Hỗ trợ tìm phòng học còn trống.

## 🔗 Liên kết

- [Trang chủ CLB Lập trình PTIT](https://clblaptrinh.ptit.edu.vn)

---

## 🛠️ Hướng dẫn cài đặt

```bash
git clone https://github.com/clb-lap-trinh/smartcampus.git
npm install
npm start
````

## 📋 Trạng thái tính năng

- Tra cứu lịch học theo mã sinh viên
- Xem danh sách phòng trống theo tòa nhà
- Thông báo đẩy (push notification)
- Đăng nhập bằng tài khoản trường
